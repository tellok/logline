# Changesets

Add an English user-facing Changeset with `pnpm changeset`. Add the matching Simplified Chinese summary to translations.json under its file ID. Version PR preparation uses the pinned CLI and beta prerelease mode.

## 变更集

通过 `pnpm changeset` 添加面向用户的英文变更说明，并在 translations.json 中以文件 ID 登记对应中文摘要。版本 PR 使用固定 CLI 与 beta 预发布模式。
